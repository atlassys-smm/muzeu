# Приложение № 11. Матрица миграции и первичного наполнения {#приложение-11.-матрица-миграции-и-первичного-наполнения}


<p>Объем фиксируется по результатам инвентаризации на согласованную дату
отсечения. Если численное значение не задано, обязательным является весь
актуальный опубликованный объем соответствующего источника, отвечающий
условиям строки. Молчаливая потеря данных не допускается.</p>

## Обязательные протоколы миграции {#обязательные-протоколы-миграции}


<ul>
<li><p>акт инвентаризации источников с количеством объектов и объемом
файлов;</p></li>
<li><p>таблица сопоставления полей, справочников и
идентификаторов;</p></li>
<li><p>отчет пробной миграции с перечнем ошибок и принятых
решений;</p></li>
<li><p>протокол итоговой загрузки, контрольных сумм и количественной
сверки;</p></li>
<li><p>протокол выборочной содержательной сверки Заказчиком;</p></li>
<li><p>реестр исключений с причиной, владельцем решения и способом
доступа к архиву;</p></li>
<li><p>план отката и подтверждение сохранности исходного
набора.</p></li>
</ul>
