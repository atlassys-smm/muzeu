# 9.5. Билетный контур {#билетный-контур}


<ul>
<li><p>встраивание виджета или интеграция по программному интерфейсу с
сохранением контекста события;</p></li>
<li><p>получение сведений о результате покупки и статусах билетов в
пределах возможностей внешней системы;</p></li>
<li><p>сопоставление билета с единым пользователем;</p></li>
<li><p>отображение QR-билета и истории;</p></li>
<li><p>передача событий покупки, возврата и посещения в CRM, аналитику и
лояльность при наличии правового и технического основания;</p></li>
<li><p>идемпотентная обработка повторных уведомлений;</p></li>
<li><p>понятные сообщения пользователю при отказе внешней
системы;</p></li>
<li><p>журналирование запросов без раскрытия чувствительных
данных;</p></li>
<li><p>совместные интеграционные испытания.</p></li>
</ul>
