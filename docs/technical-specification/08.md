# 8. Обязательные сквозные сценарии {#обязательные-сквозные-сценарии}


<p>Обязательные сквозные сценарии охватывают пользовательские,
административные, интеграционные и эксплуатационные процессы Экосистемы.
Все указанные сценарии подлежат реализации и приёмочным испытаниям.</p>
<p>Обозначения критичности:</p>
<ul>
<li><p>К — критический сценарий;</p></li>
<li><p>О — обязательный некритический сценарий;</p></li>
<li><p>К/О — составной сценарий, критичность отдельных веток которого
устанавливается настоящим ТЗ и паспортом сценария.</p></li>
</ul>
<p>Отсутствие статуса «К» не означает возможности исключения сценария из
состава Работ или приёмки.</p>

<p>Для каждого сценария Подрядчик разрабатывает паспорт в составе
программы и методики испытаний. Паспорт не может исключать
предусмотренные настоящим ТЗ роли, каналы, отрицательные ветки,
интеграции, состояния интерфейса и доказательства.</p>
<p>Один сценарий может состоять из нескольких тестовых случаев. Сценарий
считается пройденным только после успешного выполнения всех применимых
обязательных тестовых случаев во всех предусмотренных каналах. Статусы
«не проверено», «не удалось воспроизвести», «не готова внешняя система»
и «будет проверено после запуска» не означают успешного прохождения.</p>
<p>Минимальный состав приёмочных проверок и доказательств по каждому
сквозному сценарию устанавливается Приложением № 1 к настоящему ТЗ.</p>
