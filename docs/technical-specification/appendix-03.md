# Приложение № 3. Требования к дизайн-исходникам {#приложение-3.-требования-к-дизайн-исходникам}


<ul>
<li><p>экраны собраны из переиспользуемых мастер-компонентов;</p></li>
<li><p>цвета, шрифты, отступы, размеры и состояния заданы
токенами/переменными;</p></li>
<li><p>используются осмысленные названия слоев и компонентов;</p></li>
<li><p>предоставлены состояния загрузки, ошибки, пустого результата,
длинного текста и недоступности внешнего сервиса;</p></li>
<li><p>ключевые экраны имеют настольный и мобильный варианты; планшетный
— при отличающемся поведении;</p></li>
<li><p>макеты содержат правила поведения между контрольными
ширинами;</p></li>
<li><p>готовые макеты отделены от черновиков и имеют статус готовности к
разработке;</p></li>
<li><p>передаются редактируемые исходники и краткое руководство по
дизайн-системе.</p></li>
</ul>
