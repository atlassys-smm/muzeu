# 22. Исключения, допущения и зависимости {#исключения-допущения-и-зависимости}


<p>В состав Работ не входят действия, прямо не указанные в ТЗ, при этом
исключения не должны противоречить обязательным результатам.</p>
<p>Каждая внешняя зависимость должна иметь владельца, срок
предоставления, необходимый результат, альтернативный вариант и порядок
фиксации блокировки.</p>
