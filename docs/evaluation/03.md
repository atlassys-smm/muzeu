<td style="text-align: center;">1.</td>
<td style="text-align: center;">Критерий оценки «Цена контракта, сумма
цен единиц товара, работы, услуги»</td>
<td><p>Заявкам, содержащим наилучшее ценовое предложение, а также

присваивается 100 баллов.</p>
<p>Применение показателей оценки по критерию оценки «Цена контракта,
сумма цен единиц товары, работы, услуги» не допускается.</p></td>
</tr>

<td><p>Сумма величин значимости всех применяемых показателей оценки по

<tr>
<td style="text-align: center;">2.1.</td>
<td>Показатель «Качественные характеристики объекта закупки»</td>
<td><p>В отношении каждого детализирующего показателя устанавливается
значимость детализирующего показателя. Сумма величин значимости всех
применяемых детализирующих показателей по показателю оценки составляет
100 процентов.</p>
<p>Оценка заявок осуществляется по шкале оценки в соответствии с п. 22
ППРФ №2604Оценка заявки (части заявки) по критерию оценки определяется
путем суммирования среднего количества баллов, присвоенных всеми
принимавшими участие в ее рассмотрении и оценке членами комиссии по
осуществлению закупок по показателю оценки, умноженного на значимость
показателя оценки. При этом среднее количество баллов определяется путем
суммирования количества баллов, присвоенных каждым членом комиссии по
осуществлению закупок, и последующего деления на количество таких
членов.</p></td>
