# Матрица соответствия

**Предложение №3: Билетный контур и квесты.** Матрица предназначена для проверки будущих [материалов заявки](result.md) перед подачей. Сейчас это план проверки: результаты ещё не подготовлены и ни один пункт не отмечен выполненным.

## Как проводить проверку

1. Зафиксировать версию комплекта: имя файла, дату, номер версии, состав приложений.
2. По каждой строке найти конкретную схему, фрагмент описания или макета и записать номер страницы/слайда/экрана. Ссылка только на ТЗ не подтверждает наличие собственного решения.
3. Пройти схемы и расчётные примеры вручную, включая отрицательные ветви; сопоставить их между собой и с ТЗ.
4. Отдельно проверить состав по порядку оценки и связанные ограничения ТЗ. Проверка заявки оценивает предложенные решения и план работ; она не подтверждает, что система уже реализована или испытана.
5. Зафиксировать замечания, устранить их и повторно проверить изменённые строки по окончательному экспорту заявки.

**Статусы для журнала проверки:** «Не проверено», «Соответствует», «Доработать», «Нужны исходные данные/уточнение». Начальный статус всех строк — «Не проверено». Для строк обязательного состава статус «Не применимо» не используется. Для связанных требований допустимость неприменения нужно обосновать ссылкой на источник и границы предложения.

## Проверка готовности к максимальной оценке

| ID | Финальная проверка | Условие прохождения |
| --- | --- | --- |
| Ф-3-01 | Полнота | Все строки О-3 подтверждены точными местами в итоговом комплекте; ни один обязательный элемент не заменён обещанием выполнить работы. |
| Ф-3-02 | Собственные решения | В материалах можно определить, как выполняется сценарий, какие данные и системы задействованы и чем завершается каждый переход. Пересказ ТЗ не считается доказательством. |
| Ф-3-03 | Согласованность | Схемы, тексты, макеты и план работ используют одинаковые роли, идентификаторы, состояния и правила результата; существенные расхождения устранены. |
| Ф-3-04 | Ограничения ТЗ | Проверены строки Т-3; предложение не сокращает обязательный объём, не вводит противоречащие ТЗ зависимости и не выдаёт несогласованные исходные данные за подтверждённые. |
| Ф-3-05 | Основания нулевой оценки | По [перечню оснований](criterion.md#когда-выставляется-ноль) не осталось пропусков, формальных отсылок и иных указанных в порядке оценки оснований. |
| Ф-3-06 | Передаваемый файл | Все схемы, изображения и страницы присутствуют в окончательном файле заявки, читаются без закрытых ссылок и доступа к рабочим инструментам. Это внутренний контроль пригодности комплекта. |

Внутренняя цель — комплект, соответствующий условиям **100 баллов по показателю №3**. Наша проверка не заменяет решение комиссии и не создаёт промежуточную шкалу баллов. При наличии открытого замечания по обязательному элементу готовность к максимальной оценке не подтверждается.
