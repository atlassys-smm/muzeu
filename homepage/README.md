# Макет главной Бахрушинского музея

Самостоятельный HTML/CSS/JS-прототип главной Г-01–Г-09. Текущая итерация — согласование десктопа. Сборщик и установка зависимостей не требуются. MkDocs не собирает эту папку.

Из корня репозитория:

```sh
.venv/bin/python -m http.server 8001 --bind 127.0.0.1
```

Открыть: http://127.0.0.1:8001/homepage/

`index.html` — структура, `style.css` — оформление, `app.js` — данные и взаимодействия. JSON и изображения используются по относительным путям из `../docs/proposal/05-homepage-design/`, без дублирования. Поэтому сервер запускается из корня репозитория. Для отдельного размещения потребуется упаковать эти данные вместе с макетом.

Первая версия сохранена в истории описания `docs/proposal/05-homepage-design/mockups.md`. Текущий визуальный слой v2 в конце CSS переопределяет первый эскиз для сравнения направления; после согласования стили следует объединить.

Поиск работает по локальной подборке. Неопределённые сервисы открывают пояснение. Подключение к CMS и реальные сервисы не реализованы. Сокращённые заголовки — редакционные подписи для макета; исходные данные не изменяются.

Текущий Hero v3 оформлен в `hero.css`: белая основа, синий акцент, прямые сценические планы и растительный орнамент. `assets/stage-ornament.svg` — свободная графическая интерпретация завитков и ритма росписей на эскизе Н. С. Гончаровой к «Золотому петушку» (подборка, Р-П-09); не точная копия и не официальный элемент бренда. Заголовки и пояснения Hero заданы в `heroCopy` в `app.js`. JSON не изменяется.

Текущая итерация v4 заменяет Hero v3: синий фон `#343E79`, белый текст, доминирующее изображение, компактная шапка с основной навигацией и подчинёнными сервисами. `hero.css` содержит актуальные стили Hero и шапки. Орнамент отключён, SVG оставлен только как неиспользуемый эскиз.


## Полная главная · v5

Добавлены коллекции, ручной слайдер шести объектов квартала и список филиалов, новости и переход к подписке музея, промо олимпиады, витрина магазина с фильтрами и подвал. Новые блоки: `fullpage.js` и `fullpage.css`. Навигация по присланным пользователем ссылкам хранится отдельно в `data/menu.json`; её используют выпадающие меню, полный каталог разделов и подвал. Ссылки не означают, что содержание внешних разделов проверено или реализовано в прототипе.

Кнопка покупки оформлена как билет: SVG, небольшие выемки, перфорация. Все элементы сохраняют один переход к билетной афише.

Подписка ведёт на действующую страницу музея; прототип не собирает и не отправляет email. Промо содержит одну имеющуюся запись, поэтому лишних стрелок нет. Неподтверждённые бейджи удобств не выдуманы. Для объектов без собственного URL открываются локальные сведения с источником. Исторические фотографии, проект и кандидат изображения подписаны; у фотографий указаны автор и лицензия, если они известны в данных. Логотип Минкультуры в подборке отсутствует: в подвале показана текстовая ссылка; логотип Культура.РФ подключён из имеющихся материалов.
